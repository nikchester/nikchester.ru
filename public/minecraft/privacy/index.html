Minecraft server backup (rclone) — Privacy Policy

The OAuth app minecraft-backup-rclone is used only by the owner of nikchester.ru to store encrypted backups of the private Minecraft server minecraft.nikchester.ru in the owner's own Google Drive.

  • Access: the drive.file scope only — the app sees only files it created itself.
  • Data: restic-encrypted backup archives. No personal data of other users is collected, shared or sold.
  • Storage: the owner's Google Drive and the game server only.
  • Revoke access: myaccount.google.com/permissions.
  • Contact: nikchester01@gmail.com.
